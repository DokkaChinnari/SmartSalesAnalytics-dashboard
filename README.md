# 📊 Sales & Revenue Analysis Dashboard (Power BI)

## 📌 Project Overview

This project presents an interactive Sales and Revenue Analysis Dashboard developed using Microsoft Power BI. The dashboard provides valuable business insights by analyzing sales performance, customer behavior, product categories, regional sales, and returns.

It enables users to monitor key business metrics and make data-driven decisions using interactive visualizations and slicers.

---

## 🎯 Objectives

- Analyze overall sales performance
- Track revenue trends over time
- Identify top-performing product categories
- Compare regional sales
- Analyze customer segments
- Monitor returned orders
- Provide interactive business insights

---

## 🛠️ Tools Used

- Microsoft Power BI Desktop
- Microsoft Excel
- DAX (Data Analysis Expressions)
- Power Query

---

## 📂 Dataset

The project uses a retail sales dataset containing multiple tables:

- Orders
- Customers
- Products
- Returns

---

## 📈 Dashboard Features

### KPI Cards

- Total Sales
- Total Orders
- Total Quantity Sold
- Total Customers

### Visualizations

- Sales by Category
- Sales Trend
- Sales by Region
- Customer Segment Analysis
- Return Status Analysis

### Interactive Filters

- Region
- Category
- Customer Segment
- Order Date

---

## 📊 Business Insights

- Identifies the best-selling product categories.
- Compares sales performance across regions.
- Tracks yearly sales trends.
- Analyzes customer segmentation.
- Monitors product returns for better decision-making.
